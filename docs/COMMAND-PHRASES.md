# Command phrases

Start each phrase with **Hey Jarvaids**. Polite wrappers such as "could you please" and "please" also work.

Voting, to-dos, requirements and calendar execute in the shared workspace. Summary now updates the shared Overview and canvas when a summary provider is enabled. Visualisation, comparison and suggestions remain recognition-only.

In the PC launcher, usable polls open automatically and closing finishes the tally after queued replies process. Lists collect automatically and stop on close. Acceptance commands remain optional for legacy review mode.
