# Ideation

Concepts live in `concepts/`, one file each, numbered. Sketches, screenshots and
throwaway experiments live in `explorations/`.

## Rules

- A rejected concept stays in the folder. Set `status: rejected` and write the
  reason. The reason is the deliverable, not the concept.
- Every concept states what it would take to disprove it. If nothing could, it
  is a slogan, not a concept.
- Copy `concepts/_TEMPLATE.md` to start a new one.

## Status values

`exploring` -> `selected` | `parked` | `rejected`
