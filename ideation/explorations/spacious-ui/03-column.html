Column

Thesis. Take the opposite bet from Vellum. If hierarchy is genuinely carried by size, weight, contrast and position, then a screen should survive deleting every mark that is not a letter. This one does: no border, no rule, no fill, no card, no radius, no tint, no divider anywhere, with one deliberate exception, the underline on the ask field, because 1.4.11 requires an input to have a visible boundary and hiding it would be a posture, not a decision. Everything else is arranged. The transcript hangs off one shared left edge so that continuity does the work a rule would do, turns sit 44px apart while the two lines inside a turn sit 4px apart, and the session's two facts, how long it has been running and how many decisions came out of it, are set at 76px against a reading size of 19px so that the hierarchy is settled before anyone reads a word. Opacity appears here not as material but as the only thing that replaces grey: five measured steps of ink alpha, with the floor set at exactly the point where text stops being legal.

What this costs and what it buys

Design system rules broken

  • typography, no arbitrary font sizes, and the seven-size scale. This screen runs on five sizes, 76 / 34 / 19 / 15 / 12, and only two of them exist today. Buys: the reference's actual hierarchy. The shipped scale tops out at 32px and has four sizes clustered between 12 and 15, which is a scale built for density, not for glancing. 19px for speech is also the single biggest legibility gain in the whole set of five: the transcript is the densest surface in the product and 15/22 is tight for it.
  • principle 1 and the hairline vocabulary, by omission. The system separates regions with 1px hairlines. This screen has none. Buys: proof that the hairlines were never load bearing. It also costs something real: see below.
  • forbidden #1, in spirit, for the same ink alpha ladder as exploration 02. Marked PROPOSAL in the stylesheet.
  • typography, rule T1 and the h1 rule, partly. The two figures are Archivo at a size that has no Nunito partner, so the "two faces pair at the same size" measurement does not apply to them. The page also has a visible 76px number above its actual h1, which is a heading-order question the system has not had to answer before.

Rules it turned out not to need

No surface, no shadow, no gradient, no tint, no second accent, no categorical colour, no status colour reused for emphasis. A decision line is marked by weight, not by a green pill. The accent appears only on things you can click, which is exactly what principle 3 asks for and is easier to hold to here than in the shipped exemplars, because there is nothing else competing to be coloured.

The honest weakness

With nothing drawn, the screen depends entirely on its whitespace budget, and whitespace is the first thing that goes when real data arrives. Four hundred and twelve transcript lines at 44px apart is a very long page, and the moment somebody asks for a denser mode the whole argument collapses back into needing rules. The second weakness is that scan-stopping is weak: with no region edges, a reader coming back to the screen after looking away has no landmark except the figures at the top. Air handles that better with one hairline than Column does with none.

Composited contrast

The only compositing on this screen is the ink ladder over white, because there is no other ground. Computed by contrast.py in this folder. Note where the floor sits: 64% ink is the lowest alpha that still clears 4.5:1, so "faded body text" in this system stops at 64% and not a step lower.
